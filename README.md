# HR-analyst-dashboard-using-SQL-Power-BI.

This project focuses on analyzing employee attrition and workforce trends using MySQL and Power BI.
The dashboard provides key HR insights such as attrition rate, active employees, age distribution, job satisfaction, and department-wise attrition to support data-driven HR decision-making.

Tools & Technologies Used:-   

MySQL – Data extraction, transformation, and KPI calculations

Power BI – Interactive dashboard and data visualization

SQL – Aggregations, CASE statements, subqueries, GROUP BY

DAX – Measures and calculated fields

Excel – Initial data review (optional)
